# Active Directory & GPO Home Lab

This repository contains 10 simulated Tier 1 IT support tickets completed in a Windows Active Directory home lab.

## Technologies Used

- Windows Server
- Active Directory Users and Computers (ADUC)
- Group Policy Management Console (GPMC)
- Windows 10/11
- `gpupdate /force`
- `gpresult /r`

## Skills Demonstrated

- Password resets and account unlocks
- Active Directory user administration
- Security group management
- User provisioning and offboarding
- Group Policy configuration and troubleshooting
- IT ticket documentation and verification
